FILE PARSING SPECIFICATION
- Accept .csv, .xlsx, .xls through hidden file input.
- Validate file count and file size using CONFIG.MAX_FILE_COUNT and CONFIG.MAX_FILE_SIZE_MB.

- Excel parsing uses SheetJS XLSX.read(arrayBuffer,{type:"array"}); iterate workbook.SheetNames; sheet_to_json with defval:""; add __sheetName to rows.
- Each file metadata object includes id, name, type, size, rawSize, status, monthYear, rowCount and progress.
- updateProgress() updates visible percentage and progress bar, but file panel rebuilds must be throttled through scheduleFilePanelUpdate().
- processFiles() should close fileDropdown immediately after all successful files have uploaded; keep popup open if there are issues.
- renderAfterDataChange() must schedule heavy dashboard render, not block the final parsing step.
