FILE UPLOAD AND PARSING FLOW
1. User clicks 📥 Excel in dashboard ribbon.
2. Hidden file input #fileInput triggers file picker. Accept .csv, .xlsx, .xls and multiple files.
3. handleFileUpload validates extension, duplicate file, max files, max size.
4. Valid files create metadata: id, name, type, size, rawSize, status Processing/Pending, monthYear, rowCount, progress.
5. Metadata is pushed to uploadedFiles. Queue items pushed to fileQueue.
6. File panel opens so user can see parsing status.
7. processFiles takes one file at a time.
8. CSV path: FileReader.readAsText, Papa.parse header:true skipEmptyLines:true, fallbackCSVParse if Papa is missing.
9. Excel path: FileReader.readAsArrayBuffer, XLSX.read, iterate workbook.SheetNames, XLSX.utils.sheet_to_json with defval:"", add __sheetName.
10. normalizeRows normalizes column names, adds file metadata and __monthYear.
11. appendData merges rows into combinedData and updates uniqueColumns.
12. updateProgress updates percent/progress bar. updateFilePanel must be throttled through scheduleFilePanelUpdate to avoid freeze.
13. runStableProcessingProgress marks Uploaded, progress 100, and proceeds to next item after browser repaint.
14. When queue empty: renderAfterDataChange, save state, update panel, close file panel immediately if all uploaded, show toast.
15. If issues exist, keep file panel open and show error/warning toast.

BUSINESS METRICS
- Claim Count: distinct claim_number if available, else row count.
- Claimed Amount: sum claimed_amount aliases.
- Approved Amount: sum net_sanct_amt / approved aliases.
- Paid Amount: sum payment_amount aliases.
- Outstanding Amount: sum claim_r_os_amt aliases.
- Deduction Amount: disallowed_amount + copayment_amt.
- ACS: Approved Amount / Claim Count.
- Share %: Approved Amount / Total Approved Amount.
- Deduction %: Total Deduction / Claimed Amount.
- Settlement TAT: payment_date - inward_date.
- LOS: dod - doa.
- Utilization %: Approved Amount / Sum Insured.

- Business Team: Business Team card opens dashboard empty state.
- Locked roles: Other cards show restricted toast only.
- Menu hover: ☰ hover opens stable dropdown; cursor can move into list without closure.
- Menu search: Typing filters categories/items; clear x resets.

- Upload files: Excel button opens file picker, parser queue starts, file panel shows progress.
- CSV parse: CSV rows parse, normalize, append, file status uploaded.
- Excel parse: All sheets parse, normalize, append, status uploaded.
- All files done: Dashboard filters/cards render, file panel closes immediately if no issue.
- Slicer select: Open slicer, choose checkbox, menu closes, dashboard values update.
- Slicer select all: Click ✓, visible values selected, menu closes, values update.
- Slicer remove all: Click ×, slicer values clear, menu closes, values update.
- Clear all: Click broom, all filter values clear, visible boxes uncheck, values update.
- Refresh: Click ↻, dashboard values refresh smoothly.
- View switch: Click 🔀, all cards switch table/chart.
- Export: Click ⇪, export popup opens, choose export action.
- Uploaded files: Click 🗂️, file panel opens.
- User settings: Hover 👤, click ⚙ beside name, settings modal opens.
- Logout: Hover 👤, click Logout, homepage returns.
